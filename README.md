# wordspeed.pages.dev

Static site for **WordSpeed Teleprompter** — a Windows teleprompter that scrolls in words per minute.

- `/` — product page
- `/privacy/` — privacy policy (this is the URL registered in the Microsoft Store listing)
- `/assets/icon.png` — app icon

Plain HTML, no build step, no JavaScript, no external requests.

Deployed with Cloudflare Pages (GitHub integration):

| Setting | Value |
|---|---|
| Framework preset | None |
| Build command | *(empty)* |
| Build output directory | `/` |
| Production branch | `main` |
